# WebSecLab

Laboratório de segurança web desenvolvido em PHP para estudar vulnerabilidades, técnicas de exploração controlada e mitigação.

## Objetivo

O WebSecLab tem como objetivo compreender, na prática, como vulnerabilidades em aplicações web surgem, como podem ser identificadas e quais medidas podem ser utilizadas para corrigi-las.

O projeto será desenvolvido de forma incremental, com implementações vulneráveis e versões corrigidas, testes e documentação técnica.

## Vulnerabilidades estudadas

- [X] SQL Injection
- [ ] Cross-Site Scripting (XSS)
- [ ] Authentication
- [ ] Session Management
- [ ] IDOR e Broken Access Control
- [ ] Cross-Site Request Forgery (CSRF)
- [ ] Path Traversal
- [ ] File Upload
- [ ] Command Injection

## Tecnologias

- PHP
- HTML, CSS e JavaScript
- MariaDB
- Docker e Docker Compose
- Git e GitHub

## Metodologia

Cada laboratório seguirá este ciclo:

1. Construção da implementação vulnerável.
2. Análise da causa da vulnerabilidade.
3. Demonstração controlada em ambiente local.
4. Documentação do impacto.
5. Implementação da correção.
6. Testes para validar a correção.
7. Registro das diferenças entre as versões.

## Segurança e uso autorizado

Este projeto é destinado exclusivamente ao aprendizado, a testes locais controlados e a ambientes para os quais exista autorização explícita.

As implementações vulneráveis deverão ser isoladas e não destinadas à exposição pública.
