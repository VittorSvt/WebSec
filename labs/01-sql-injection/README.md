
# Lab 01 — SQL Injection

## Objetivo

Compreender como a concatenação insegura de entradas do usuário em consultas SQL pode causar SQL Injection.

## Cenário

Uma aplicação PHP consulta registros fictícios armazenados no MariaDB.

## Laboratório vulnerável

Pendente de implementação.

## Correção

Pendente de implementação com prepared statements.

Pendente.
